## Суть продукта

**ИИ-агент для предпринимателя-деревяшки** — бот, который умеет:
- Общаться с клиентами (продажи, поддержка)
- Отвечать на вопросы о бизнесе
- Вести диалог без "ой всё сломалась"
- Работать 24/7

**Целевой клиент:** Малое предприятие (строительная база, гончарная студия, etc.)
- Не шарит в IT
- Не понимает как работает ИИ
- Хочет "просто чтобы работало"
- Боится что бот будет тупить

---

## Этапы продажи и настройки

### 1. PRE-SALE — понять клиента
- [ ] Что за бизнес?
- [ ] Кто его клиенты?
- [ ] Какие вопросы задают чаще всего?
- [ ] Чем сейчас отвечают (телефон, WhatsApp, etc.)?
- [ ] Сколько времени уходит на ответы?

### 2. ONBOARDING — установить и настроить
- [ ] Создать Telegram бота
- [ ] Подключить к OpenClaw
- [ ] Настроить голос (TTS)
- [ ] Загрузить базовую информацию о бизнесе
- [ ] Протестировать — Олег проверяет, не клиент

### 3. POST-SALE — первые 2 недели
- [ ] Мониторить каждый день (3 раза)
- [ ] Собирать pain-log (что клиент не понял, где тупит)
- [ ] Корректировать бота
- [ ] Объяснять клиенту как пользоваться

### 4. PRODUCTION — стабильная работа
- [ ] Еженедельная проверка метрик
- [ ] Обновления на основе pain-log
- [ ] Следующий клиент получает бота ОБУЧЕННОГО на граблях предыдущего

## Чеклист настройки агента

```
1. Базовая информация:
   - Название компании
   - Что продаёт
   - Цены (если публичные)
   - Контакты
   - FAQ ( топ 10 вопросов)

2. Поведение:
   - Стиль общения (формальный/неформальный)
   - Как отвечать на "а если..."
   - Как переводить на человека если тупит

3. Техническое:
   - cron_mode = allow
   - tirith_enabled = false (или true если нужен)
   - timeout настроить под запросы
   - auto_tts проверить

4. Тест:
   - ОЛЕГ ПРОВЕРЯЕТ ПЕРЕД ОТДАЧЕЙ
   - Клиент НЕ должен видеть косяки
```

## Типичные грабли и решения

| Проблема | Решение |
|----------|---------|
| Клиент не понимает что это бот | Сказать сразу: "Я ИИ-ассистент" |
| Бот тупит на сложных вопросах | Инструкция: "переведу на человека" |
| Клиент думает что бот знает всё | Ограничить: "Я знаю только о..." |
| Бот отвечает слишком долго | timeout=30s, человеку: "секунду" |

## Следующий клиент

Каждый новый клиент должен получить агента,
который уже обучен на граблях предыдущего.

**Формула:**
```
Грабли Nikolay + Решения → Добавить в Pain Log →
Обновить чеклист → Следующий клиент получает ЛУЧШЕ
```
