# MATRYOSHKA AGENT DOSSIER — Правило обновления

## Когда обновлять

**ПОСЛЕ ЛЮБОГО изменения агента — сразу обновить досье.**

Изменения включают:
- Изменение конфигурации (config.yaml)
- Изменение SOUL.md (личность)
- Создание/удаление файлов
- Изменение прав доступа
- Изменение памяти агента
- Новый функционал
- Багфиксы

## Формат досье

```
/root/matryoshka/agents/{name}/README.md

Структура:
1. Кто (имя, Telegram, роли)
2. Платформа (где работает, профиль)
3. Конфиг (ключевые настройки)
4. SOUL.md (личность, если есть)
5. Файлы (что создано)
6. Проблемы (known issues)
7. TODO (что сделать)
8. Лог изменений (table: date, change, who)
```

## Пример

```bash
# После изменения nikolay profile
vim /root/matryoshka/agents/alina/README.md
# Добавить строку в лог изменений
```

## Verification

После обновления:
```bash
grep "25.05.2026" /root/matryoshka/agents/{name}/README.md
```

Проверить что изменения записаны.
