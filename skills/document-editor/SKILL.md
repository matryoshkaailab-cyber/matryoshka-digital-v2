# ✏️ DOCUMENT EDITOR — Редактирование документов

## РОЛЬ
Ты умеешь редактировать существующие документы: изменять текст, таблицы, изображения.

## ВОЗМОЖНОСТИ

### 1. Чтение DOCX
```python
from docx import Document

doc = Document('/tmp/document.docx')
for para in doc.paragraphs:
    print(para.text)
```

### 2. Редактирование текста
```python
# Поиск и замена текста
for para in doc.paragraphs:
    if 'старая цена' in para.text:
        para.text = para.text.replace('старая цена', 'новая цена')
```

### 3. Редактирование таблиц
```python
# Изменение ячеек
table = doc.tables[0]
table.cell(0, 0).text = 'Новое название'
table.cell(1, 1).text = 'Новое значение'
```

### 4. Добавление контента
```python
# Добавить абзац
doc.add_paragraph('Новый текст')

# Добавить таблицу
table = doc.add_table(rows=3, cols=3)

# Добавить изображение
doc.add_picture('/tmp/logo.png', width=Inches(2))
```

## ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Обновление прайса:
```
Пользователь: "Обнови прайс, добавь новый гель +500₽"
Ты:
1. Открываешь /tmp/прайс.docx
2. Находишь таблицу с услугами
3. Добавляешь строку: "Новый гель — 500₽"
4. Сохраняешь: /tmp/прайс_новый.docx
5. Отправляешь пользователю
```

### Правка договора:
```
Пользователь: "В договоре для Марии измени цену на 1500₽"
Ты:
1. Открываешь договор_Мария.docx
2. Находишь строку с ценой
3. Меняешь: 1000₽ → 1500₽
4. Сохраняешь версию 2
5. Отправляешь пользователю
```

### Актуализация отчёта:
```
Пользователь: "Добавь в отчёт данные за сегодня"
Ты:
1. Открываешь отчёт_месяц.docx
2. Находишь таблицу с метриками
3. Добавляешь строку с сегодняшними данными
4. Пересчитываешь итоги
5. Сохраняешь обновлённую версию
```
