🔄 Порочные круги экономической системы

🕳️ Инвестиционная ловушка

Низкая отдача 0.2–0.3 ВВП/руб. → нет роста → нет прибыли → нет инвестиций → стагнация

👥 Демографическая яма

Убыль населения → сокращение рабочей силы → нагрузка на пенсионную систему → дефицит бюджета

🔌 Цифровой застой

Блокировки → уход технологий → отставание → изоляция → новые блокировки

📊 Статистический разрыв

Официальная 5.9% vs ощущаемая 13–15% → недоверие к данным

📋 Рекомендации

🏛 Для государства

  • Сместить фокус: военные → человеческий капитал
  • Реформировать налоговую для МСП
  • Создать независимый институт оценки
  • Восстановить доверие через прозрачность
  • Стимулировать частные инновации

🏢 Для бизнеса

  • Диверсификация: рынки, поставщики, каналы
  • Инвестиции в автоматизацию
  • Офлайн-процессы на случай сбоев
  • Участие в отраслевых ассоциациях
  • Фокус на экспорт в дружественные страны

👤 Для граждан

  • Диверсификация сбережений
  • Контроль долговой нагрузки ≤30%
  • Инвестиции в навыки
  • Критическое потребление информации
  • Гражданская активность
