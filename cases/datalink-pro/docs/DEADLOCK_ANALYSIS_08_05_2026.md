## 4. ВОЗМОЖНЫЕ ПРИЧИНЫ ПРОВАЛА ПОРТА 443

### Гипотеза 1: xtls-rprx-vision заблокирован
- Порт 443 - стандартный HTTPS порт
- Но xtls-rprx-vision имеет специфичный TLS fingerprint
- ТСПУ может детектировать и блокировать этот трафик

### Гипотеза 2: Конфликт с Nginx
- Nginx слушает 443 (но сейчас не запущен)
- Возможен конфликт при старте xray

### Гипотеза 3: Firewall блокирует 443
- iptables может блокировать входящие на 443
