# Финансы nikolay-phone

## Структура
- purchases.csv — закупки iPhone
- sales.csv — продажи

## Команды для Алины
- "купил iPhone 11 за 15000" → записать в purchases.csv
- "продал iPhone 11 за 25000" → записать в sales.csv, посчитать маржу

## Отчёты
- Ежедневный: /finances/reports/daily_YYYY-MM-DD.md
- Месячный: /finances/reports/monthly_YYYY_MM.md
