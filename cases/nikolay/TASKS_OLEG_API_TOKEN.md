## 🎯 ЦЕЛЬ

Получить **client_id** и **client_secret** от Avito Partner API, чтобы Алина могла **автоматически размещать объявления** через официальный API.

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ

### Шаг 1: Зарегистрироваться как партнёр
1. Открой **https://developers.avito.ru/**
2. Нажми **"Войти"** → войди через Avito (аккаунт Николая или свой)
3. Перейди в **"Личный кабинет"** → **"Мои приложения"** → **"Создать приложение"**

### Шаг 2: Заполнить форму
- **Название:** `MATRYOSHKA-ALINA`
- **Описание:** `Бот для автоматизации бизнеса Николая (iPhone-перепродажа, Краснодар)`
- **Redirect URI:** `https://matryoshka-digital.ru/callback` (можно любой, для client_credentials не нужен)
- **Тип авторизации:** ✅ **client_credentials** (НЕ authorization_code!)

### Шаг 3: Получить credentials
После создания приложения увидишь:
- **client_id** (длинная строка)
- **client_secret** (ещё длиннее, СЕКРЕТ — никому не показывай!)

### Шаг 4: Положить на VPS
```bash
# На VPS
mkdir -p /root/matryoshka/SECRETS
cat > /root/matryoshka/SECRETS/avito_api.json << 'JSON'
{
  "client_id": "ТУТ_CLIENT_ID",
  "client_secret": "ТУТ_CLIENT_SECRET"
}
JSON
chmod 600 /root/matryoshka/SECRETS/avito_api.json
```

### Шаг 5: Проверить что работает
```bash
cd /opt/avito_parser
python3 avito_api.py test
```
Должен вернуть: **"✓ ТОКЕН РАБОТАЕТ!"** + профиль
