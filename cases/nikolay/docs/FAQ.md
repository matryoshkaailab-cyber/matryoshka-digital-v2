## Q: Почему Алина иногда "тупит"?

**Честные причины:**

1. **MiniMax-M3 упал** — fallback на более слабую модель (отвечает медленнее и короче)
2. **Сеть лагает** — VPS в Чехии, связь с API до 5 сек
3. **Длинный промпт** — если SOUL.md (12 KB) + длинный вопрос, ответ дольше
4. **HTTP 429** — Apify rate limit (только для парсинга)

**Что НЕ делать:** не спамить, не отправлять одно и то же 10 раз. Лучше подождать 5 сек.

## Q: Как дать ей новый навык?

Через **skill** (как у HERMES):

```bash
# 1. Найти подходящий skill
ls /root/.hermes/profiles/hermes-cli/skills/

# 2. Создать symlink в Алине
ln -s /root/.hermes/profiles/hermes-cli/skills/matryoshka/X \
      /root/.hermes/profiles/alina/skills/X

# 3. Добавить в whitelist cleanup
nano /root/matryoshka/cases/nikolay/alina_skills_cleanup.sh
# KEEP+=( "X" )

# 4. Рестарт
systemctl restart alina-gateway
```

**Или попросить HERMES** — он может создать новый skill специально для Алины.

**Да.** Всё на VPS (Германия/Чехия через SmartApe). Никуда не уходит.

**Что НЕ отправляется наружу:**

**Бэкап:** Яндекс.Диск, 2:00 daily (зашифрованный архив).

## Q: А если VPS упадёт?

- VPS у SmartApe (99.9% SLA) — падает редко
- Если упал → Алина тоже недоступна
- Когда VPS поднимется → systemd автоматически запустит:
  - alina-gateway (через 15 сек)
  - alina-server (через 10 сек)
- Telegram очередь: при падении бота сообщения **НЕ теряются** (Telegram хранит до 24ч)

**Когда Олег узнает:** через `alina_monitor.py` (каждые 5 мин от HERMES).

## Q: HERMES может "сломать" Алину?

**Нет.** HERMES — **только читает** alina_status.json и алертит при проблемах. Не управляет процессами Алины.

**Исключение:** если Олег скажет "почини Алину" — HERMES может:
- Перезапустить сервисы
- Исправить конфиг
- Обновить SOUL.md
- Добавить/убрать skill

Но это **по команде**, не автоматически.

## Q: Что такое alina_tasks/?

Папка-мост с HERMES. Содержит:

| Файл | Кто пишет | Кто читает |
|------|-----------|-----------|
| `TASK_*.md` | HERMES (задачи для Алины) | alina-bridge-hermes (каждые 2 мин) |
| `DONE_*.md` | Алина (результаты) | HERMES (мониторит) |
| `STATUS_*.md` | Алина (алерты) | HERMES |
| `alina_status.json` | alina_status.sh | HERMES alina_monitor.py |

**Пример задачи:**
```markdown
# TASK от HERMES
Аудит карточек Авито за неделю. Найди топ-3 по конверсии.
```

Алина прочитает (через bridge), обработает, запишет в `DONE_*.md`.

## Q: Можно ли Алину сделать мультиязычной?

**Нет (by design).** SOUL.md запрещает английский. Это:
- Деловое решение (Николай говорит по-русски)
- Безопасность (мультиязычные боты часто взламывают через EN-промпты)
- Стоимость (мультиязычные модели дороже)

Если нужен EN-бот — создай клон с другим SOUL.md.

## Q: Как Алина отвечает если модель не отвечает?

Fallback chain (5 моделей):
1. MiniMax-M3 (primary)
2. MiniMax-M2.7
3. Gemini 2.5 Flash (через OpenRouter)
4. Claude 3 Haiku (через OpenRouter)
5. Qwen 3.7 Plus (локально)

Если **все 5 упали** → возвращает `ok=false`. HERMES получает ошибку и может:
- Попробовать позже
- Ответить Николаю "Алина временно недоступна"
- Алертнуть Олегу
