# MATRYOSHKA DIGITAL — сайт v1

Статический лендинг MATRYOSHKA DIGITAL.

Файл:
- `/root/matryoshka/site/index.html`

Содержит:
- hero-секцию с позиционированием компании;
- схему AI-оркестра HERMES → ALEX / ALF / ALINA / ALISA;
- направления: AI-сотрудники, автоматизация, инфраструктура, цифровые продукты, разведка, контент;
- процесс работы: разобрал → заархитектурировал → реализовал → проверил → передал;
- блок кейсов: DATALINK PRO, ЛЕГИОН VR, ЭКЛЕР / ALINA, HERMES ORCHESTRA;
- CTA на Telegram Олега.

Как открыть локально:
```bash
python3 -m http.server 8765 --directory /root/matryoshka/site
```

После запуска открыть:
```text
http://127.0.0.1:8765/
```

Публикация:
- можно положить в nginx как статический сайт;
- можно привязать к домену `matryoshka-digital.ru` или отдельному поддомену;
- перед боем заменить CTA/контакты на финальные и добавить реальные ссылки.
