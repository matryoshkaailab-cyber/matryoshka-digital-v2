# 🦾 ALINA_HANDS — Архитектура "Руки Алины"

**Цель:** Превратить Алину из болталки в ИСПОЛНИТЕЛЯ с навыками
**Для кого:** CLIENT_001 (клиент, перекупщик iPhone) + будущие клиенты
**Опыт:** дублируется на других клиентов МАТРЁШКА

---

## 🎯 Принцип

> **Алина = мозг Николая в Telegram. SOUL = её характер, HANDS = её умения.**

**HANDS** — это набор **модулей-инструментов**, которые Алина вызывает по команде или по контексту разговора.

```
CLIENT_001: "Найди iPhone 13 до 25000 в Москве"
    ↓
Алина (SOUL) понимает запрос
    ↓
ALINA_HANDS вызывает: tools.avito_parser.parse_avito("iPhone 13", 25000, "msk")
    ↓
Результат → Алина форматирует голосом + отправляет ссылки
    ↓
CLIENT_001: "О, первый норм, давай оформим"
    ↓
ALINA_HANDS вызывает: tools.avito_api.create_ad(lot_data)
    ↓
Готово — объявление на Avito
```

## 📐 КОНТРАКТ МОДУЛЯ (как пишем)

Каждый инструмент — **один файл** в `hands/`, с такой структурой:

```python
# hands/avito_parser.py
"""
Парсер Avito — для Алины (вызывается ею когда CLIENT_001 просит найти товар)
Запускается на VPS (requests) или ПК Аликса (Selenium+куки)
"""

def parse_avito(query: str, max_price: int, city: str = "msk", limit: int = 10) -> list[dict]:
    """
    Args:
        query: что ищем ("iPhone 13 128GB")
        max_price: верхняя граница цены
        city: msk / spb / krd / all
        limit: макс. результатов

    Returns:
        [
            {
                "id": "avito_xxx",
                "title": "iPhone 13 128GB",
                "price": 24000,
                "url": "https://...",
                "photos": ["url1"],
                "seller": "Иван",
                "city": "Москва"
            },
            ...
        ]

    Raises:
        BlockedError: если IP забанен
        ParseError: если Avito сменил вёрстку
    """
    # ... код
```

**Правила:**
1. ✅ Один файл = один инструмент
2. ✅ Чистая функция (без глобалов)
3. ✅ Type hints везде
4. ✅ Docstring с примером вызова
5. ✅ Тест в `tests/test_*.py`
6. ❌ НЕ лезть в SOUL.md
7. ❌ НЕ дёргать Telegram напрямую
8. ❌ НЕ хранить секреты в коде (только через env)

## 🔗 КАК АЛИНА ВЫЗЫВАЕТ ИНСТРУМЕНТЫ

Через **tool_call** в Hermes:

```python
# В SOUL.md Алины:
TOOLS:
  - name: "Найти товар на Avito"
    function: hands.avito_parser.parse_avito
    triggers: ["найди", "ищи", "покажи лоты", "что есть на авито"]
    args: извлечь из контекста (query, max_price, city)
```

**Когда CLIENT_001 говорит → Алина решает какой tool вызвать → tool возвращает данные → Алина отвечает голосом + текстом.**

## ⚠️ ВАЖНО — БАН VPS IP

**Avito ЗАБЛОКИРОВАЛ VPS IP (85.137.166.209).** Это значит:
- ❌ Selenium + VPS IP = бан
- ❌ Прямой requests с VPS = бан

**Решения:**
- 🅰️ **Yandex fallback** — парсить через Yandex XML (пока делаем 30 мин)
- 🅱️ **Через ПК Аликса** — Selenium на домашнем IP OLEGа (надёжно, медленно)
- 🅲️ **Avito API** — когда OLEG зарегистрирует партнёра (правильный путь)

**Первый модуль (avito_parser) — ПИШЕТ АЛИКС**, потому что:
- Нужны куки из Chrome OLEGа
- Прокси-схему он настроит быстрее
- VPS сейчас не может парсить
