# MATRYOSHKA DIGITAL — Claude Code Instructions

## Разрешения
- Bash команды — выполнять без подтверждения
- Файлы — читать/писать без подтверждения
- SSH на серверы — разрешено
- Python скрипты — запускать напрямую

## Контекст проекта
MATRYOSHKA DIGITAL — AI-операционная система для бизнеса. Multi-agent команда (Алекс, Эклер, Алина) на базе OpenClaw, управляемая через Telegram. n8n workflow автоматизация.

## Серверы
- Основной сервер: проверять в .env файле (переменная SERVER_IP)
- SSH ключи: стандартные для пользователя

## Стек
- OpenClaw (AI агенты)
- Docker (контейнеры)
- OpenRouter API (AI модели)
- n8n (workflow автоматизация)
- Telegram Bot API
- Yandex SpeechKit (STT/TTS)
- Yandex Disk (WebDAV)

## AI Агенты
- **Алекс** (@oleg_industry_bot) — координатор, для Олега
- **Эклер** (@ZarnyAlexaBot) — аналитик, для Натальи
- **Алина** (@NikolaAlinaBot) — продажник, для Николая

## Поведение
- Действовать автономно, не спрашивать лишних подтверждений
- При изменении конфигов — всегда делать бэкап
- Логи искать в /var/log/ на сервере
- Бот запускается через systemd или screen
